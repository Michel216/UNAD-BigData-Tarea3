## Descripción del Proyecto
Implementación de procesamiento de datos en lote (Batch) sobre el dataset de Calidad del Aire de Colombia. Se realiza el parsing de registros JSON multilínea con PySpark para calcular estadísticas agregadas de concentración (promedio, máximo y mínimo) por estación y variable de monitoreo.

## Estructura del Repositorio
* `Untitled.ipynb`: Cuaderno de Jupyter Lab con el código y la ejecución en PySpark.
* `calidad_aire.csv`: Dataset original descargado.
* `resultado_batch_calidad_aire/`: Archivo consolidado de resultados en CSV.
